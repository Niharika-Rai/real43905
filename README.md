This repository is for the Real Estate Industry Project Class (REAL 43905). 
Our project is to develop an app, hosted on Render, to solve a real-life real estate issue. 
Our main issue is affordable housing. 
Hence, our app will help developers choose sites to build more affordable housing units in U.S. Metro Areas where there is both strong need and it is financially profitable to build.
It will also have financing recommendations for individual homebuyers seeking to purchase affordable homes.
